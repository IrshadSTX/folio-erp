# Folio ERP — Mobile UI/UX Prototype

A modern, mobile-first ERP / billing / accounting prototype designed for client approval before Flutter implementation.

## Preview
Open [`index.html`](./index.html) in any modern browser.

## What's inside
- **26 mobile mockups** across 6 sections (onboarding, dashboard, sales, customers, proposals, system states)
- **Full design system** in `assets/css/main.css` (tokens, components, dark mode)
- **Light & dark themes** — toggle from the top toolbar
- **Device size switcher** (S / M / L)

## Structure
```
.
├── index.html              # Design board with all 26 screens
├── assets/
│   ├── css/main.css        # Design tokens & components
│   └── js/main.js          # Theme & device-size toggles
└── README.md
```
